# Atom

This repository only hosts Atom's installers. Atom updates itself once installed.

## Install

1. Open the [latest release](https://github.com/helamxn/atom-releases/releases/latest).
2. Download `atom_<version>_x64-setup.exe`.
3. Run it. If Windows SmartScreen shows a warning, choose **More info → Run anyway**.

Atom runs on Windows 10 and 11 (64-bit).

## Updates

Atom checks for new versions while it runs and offers to install them. Download
the installer again only if you uninstalled Atom.
